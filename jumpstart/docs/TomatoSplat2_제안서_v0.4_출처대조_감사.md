- **후속 사용자 요구**: 기준 문서 작성 후 대화에서 사용자가 명시적으로 추가한 방향

- **확정도 변경**: 기준 문서에서 제안 또는 미정인 항목을 v0.4에서 확정된 것처럼 표현함
- **충돌 가능성**: 기준 문서의 기존 방향과 강조점 또는 단계가 달라짐

## 2. 결론

v0.4의 **게임 본체에 관한 내용은 대부분 두 기준 문서에 기반한다.** 다음 핵심 요소는 모두 직접 근거가 있다.

- 휠윈드 자동 전투 기반 방치형 핵앤슬래시
- 토마토와 케첩으로 표현하는 무혈 카니지
- 생존 손실 대신 시간·파밍 효율로 표현하는 실패
- 훈련과 전투의 교대, `훈련은 입장권 / 무기는 클리어권` 구조
- 전투장 12개 × 웨이브 20개
- 개인 인스턴스와 8인 서버
- 감지 반경 추적 AI와 토마토 유형 4종
- 한손 대형 무기와 쌍수의 비대칭
- 티어 12 × 등급 5 × 타입 2의 무기 구조
- 랜덤 옵션, 소켓, 보석, 행운과 타격 시 발동 스킬
- 자동화 원칙과 성장원 역할 분리
- 출시 콘텐츠 볼륨
- V1 6주 출시, 아트 디렉터 경력과 검증 자산
- M0~M5 검증 게이트 구조

그러나 v0.4 전체가 두 문서만으로 작성된 것은 아니다. 추가된 내용은 크게 세 종류다.

1. **후속 사용자 요구로 추가된 방향**
   - 모바일 네이티브 포지셔닝
   - 폭넓은 저사양 모바일 환경에서 고밀도 전투를 구현한다는 목표
   - 작업자별 가용 시간과 작업량을 취합한 뒤 일정을 확정한다는 일정 수립 원칙

2. **소개 문서 작성을 위해 임의로 재구성했던 표현**
   - `Accessible Loot ARPG` — 폐기
   - `Build Decisions / Growth Priorities` — 폐기
   - `Carnage Without Gore` — 폐기
   - `모바일 네이티브 Loot ARPG` — 폐기
   - 장르·게임플레이·인터랙션의 세 축으로 정리한 Novelty — 원문의 평이한 설명으로 교체

3. **기준 문서에 없는 구체적 신규안 또는 확정도 변경**
   - 거리·화면 점유율 기반 VFX LOD
   - 적·드랍·VFX 오브젝트 풀링
   - 디바이스별 그래픽 품질 단계
   - 장비·보석 프리셋 유료 확장
   - 무기·휠윈드·드랍·이동 연출 외형 상품
   - 기간형 상품
   - 일부 마일스톤의 범위 및 순서 변경
   - 미정인 프리즘 보상 방식과 오프라인 보상을 확정안처럼 표현한 부분

따라서 v0.4는 **기준 문서 기반의 소개문**이지만, 기준 문서의 단순 요약본은 아니다. 아래 신규·확장 항목은 확정 전에 별도 승인 또는 GDD 반영이 필요하다.

## 4. 기준 문서에 없는 신규 추가 사항

### 4.1 후속 사용자 요구로 정당화되는 추가

다음 내용은 두 기준 문서에는 명시되지 않았지만 이후 사용자가 직접 요구한 방향이므로, v0.4에 포함할 수 있다. 다만 향후 기준 GDD에도 반영해야 문서 간 기준이 일치한다.

| 추가 내용 | v0.4 위치 | 상태 |
|---|---:|---|
| 폭넓은 모바일 환경에서의 전투 성능 목표 | 모바일 전투 설계 절 | 사용자 요구. `모바일 네이티브 Loot ARPG`라는 별도 장르 표현은 폐기 |
| 모바일과 서버 성능을 분리해 검증 | 217행 | 사용자 요구를 실행 항목으로 구체화 |
| 목표 출시일 역산이 아닌 작업자 가용 일정 기반 계획 | 282~308행 | 사용자 요구 |
| 작업자 상세 산정 후 마일스톤 날짜 확정 | 286~308행 | 사용자 요구 |

### 4.2 편집상 추가된 명칭과 해석

다음은 새로운 기능이 아니라 기준 문서의 내용을 설명하기 위한 상위 표현이다.

| 표현 | 근거가 된 기존 내용 | 판단 |
|---|---|---|
| Accessible Loot ARPG | 시간 없는 성인을 위한 ARPG, 깊이는 유지하고 노동 자동화 | 출처 없는 합성 장르명으로 폐기 |
| Carnage Without Gore | `고어가 아니라 케첩` | 출처 없는 영문 슬로건으로 폐기하고 원문 사용 |
| 압도·발견·성장 | 압도 판타지, 희귀 드랍, 장기 성장 | 유지 가능 |
| Build Decisions / Growth Priorities | 아이템 조합과 성장 트리라는 두 고민 지점 | 출처 없는 임의 분류로 폐기 |
| 생존 압력을 파밍 효율로 전환 | 죽음 손실을 웨이브 리셋과 시간 손실로 대체 | 유지 가능 |
| 직접 플레이와 자동 성장의 연속성 | 수동 입력 시 자동 전투 해제, 풀링 자동 전투 | 유지 가능 |

### 4.5 일정 계획에서 새로 추가된 내용

다음은 게임 기능 추가가 아니라 후속 사용자 지시에 따라 새로 작성된 프로젝트 관리 방식이다.

- 담당자별 작업 분해와 예상 작업량 제출
- 주간 가용 시간 및 선행 작업을 반영한 통합 일정
- 기술 불확실성에 대한 검증·수정 기간
- 마일스톤별 일정 확정 기준
- 마일스톤별 주요 일정 변수
- M4 결과와 첫 업데이트 준비 상태를 함께 검토한 뒤 출시일 확정

이 내용들은 두 기준 문서에는 없지만 사용자가 직접 지정한 일정 수립 원칙과 일치한다.

## 5. 확정도 또는 단계가 달라진 항목

### 5.1 프리즘형 보상 방식

- v0.4: 프리즘형이 타격할 때 Coin과 무기를 흘리는 것으로 확정 서술
- GDD 본문: 타격당 보상 방식으로 설명
- GDD §21.2: `타격당 즉시 흘림 vs 체류 종료 시 일괄` 미결정

**판정:** 기준 GDD 내부에서도 확정도가 일치하지 않는다. v0.4에서는 `Coin·무기 보상에 특화된 대상` 정도로 완화하는 것이 안전하다.

### 5.2 오프라인 보상과 오프라인 시간 확장 BM

- v0.4: `오프라인 시간과 편의 기능 확장`을 수익화 항목으로 제시
- GDD §16: 오프라인 보상은 도입 근거와 권장안이 있으나 최종 결정 전
- GDD §19: BM 목록에는 오프라인 시간 확장이 포함
- GDD §21.2: 오프라인 보상 최종 결정이 남아 있음

**판정:** GDD 내부에 계획과 미결정 표시가 공존한다. 오프라인 보상 자체가 확정되기 전까지 제안서에서는 `도입 시 확장 가능한 편의 기능`으로 표현해야 한다.

### 5.3 자동 전투의 마일스톤 배치

- v0.4 M1: 직접 조작과 자동 전투 전환 포함
- 제안서 v0.3 M1: 인스턴스·웨이브·드랍·강화의 최소 파밍 루프
- 제안서 v0.3 M2: 자동 전투와 자동화 일체

**판정:** 기능 자체는 기준에 있으나 구현 시점을 M2에서 M1으로 앞당겼다. 수직 슬라이스에서 핵심 인터랙션을 보여주려는 의도라면 일정 변경 승인이 필요하다.

### 5.4 M4의 검증 범위

- v0.4 M4: 디바이스별 품질 조정, 리텐션·경제·수익화 실험 포함
- 제안서 v0.3 M4: 최종 3D 월드, UI 폴리시, 튜토리얼 동선, 첫 세션 지표

**판정:** 소프트 런치 단계의 일반적인 업무로는 타당하지만 원문보다 범위가 넓다. 담당자 일정 산정 시 추가 작업량으로 계산해야 한다.

### 5.5 비주얼에서 배경의 위상

- v0.4: 배경 복잡도보다 플레이 순간의 가독성과 반응성이 중심
- 제안서 v0.3: 신규 월드 지형과 배경 품질, 추가 UV 기반 텍스처·셰이더 지원을 중요한 목표로 제시

**판정:** 직접 충돌은 아니지만 강조점이 달라졌다. `타격이 첫인상을 만들고, 배경이 그 품질을 지지한다`처럼 두 목표의 관계를 명확히 할 필요가 있다.

## 9. 최종 판정

현재 v0.4의 **게임 콘셉트와 핵심 시스템은 기준 문서에 충실하다.** 새 게임 시스템을 임의로 대규모 추가한 문서는 아니다.

다만 다음 세 영역은 기준 문서만으로는 확정할 수 없다.

- 모바일 최적화의 구체적인 구현 방식
- 외형·프리셋·기간형 상품을 포함한 수익화 확장안
- 작업자 산정 기반의 상세 일정 관리 방식

이 가운데 모바일 목표와 일정 관리 방식은 후속 사용자 요구에 따라 추가된 내용이다. 수익화 확장안과 일부 최적화 구현안은 작성 과정에서 구체화된 제안이므로, **확정 계획이 아니라 검토 항목으로 분리하는 것이 가장 정확하다.**

## 10. 후속 설계 변경 — 성장 작업의 자동화 범위

2026-08-02 사용자 검토에서 강화, 합성, 분해, 포인트 투자와 펫 합성은 모바일 플레이의 핵심 재미를 구성하므로 기본 자동화 대상으로 설명하지 않기로 했다.

### 기존 기준 문서

- 제안서 v0.3 §3: 강화, 하위 등급 합성, 잡템 분해와 포인트 투자를 원클릭·필터·프리셋으로 자동화
- GDD §14.1: 원클릭 최대 강화, 자동 분해, 자동 합성, 포인트 프리셋 투자와 펫 자동 합성을 자동화 대상으로 지정

### 후속 변경 방향

- 강화·합성·분해·성장 투자는 전리품을 성장으로 바꾸는 직접 플레이로 유지
- 플레이어가 획득물을 확인하고 처리한 뒤 다음 전투를 준비하는 세션 리듬을 보존
- 물량 증가 이후 다중 선택, 일괄 처리와 조건 설정을 편의 기능으로 단계적 제공
- 자동화의 해금 시점과 범위는 별도 설계 필요

### 문서 상태

v0.4 제안서는 후속 방향으로 수정했다. 두 기준 문서는 아직 기존 자동화 원칙을 유지하고 있으므로, 구체적인 조작 방식과 단계별 편의 기능이 결정되면 GDD 및 v0.3에도 동일하게 반영해야 한다.
