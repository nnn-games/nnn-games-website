### 16장 월간 타임라인

각 단계 카드 우상단에 프로젝트 대표 이미지를 원본 비율로 작게 표시합니다. 하단은 2026년 9월~2027년 2월 월간 타임라인이며, 세 프로젝트 모두 2026년 9월 시작입니다. 파랑(Enchant a Weapon)은 10월, 초록(Hunt a Slime)은 11월, 빨강(Tomato Splatter)은 2027년 2월 출시 예정까지 기간을 표시합니다. 각 기간 막대의 2026-10-02 위치에 현재 진척도 60%·25%·5%를 배지로 표시합니다. 기간 막대의 길이는 개발 예정 기간이고 배지 값은 현재 작업 완료율이므로 기간상의 진행 위치와 완료율을 혼동하지 않도록 구분합니다. 월별 예상 진척도는 추정하지 않습니다. 9월 시작일의 일자는 미지정으로 월 단위 표시합니다. 현재 배지 위치는 10월 칸 내 2일에 해당하는 공통 위치입니다.

### 20장 연구의 실전 적용

사용자 제공 [연구 적용 문서](roblox_research_to_project.md)를 요약했습니다. 원문은 자료로만 다루고 공개 링크의 초록·공식 설명을 2026-10-02 확인했습니다. 3D 생성(Cube), 메시 최적화(Textured Mesh Simplification·Line Quadrics), 캐릭터 셋업(Automatic Avatar Setup·CageNet), 월드 최적화(SLIM)의 4영역과 제작 흐름을 KO/EN으로 표시합니다. 20장은 카드·BibTeX 없이 1열 노트 형태로 발표 연도·연구 제목 6종과 적용 연구 분야를 나열합니다. Cube는 3D 에셋·지형 제작, Avatar Setup·CageNet은 NPC·캐릭터 제작, Textured Mesh·Line Quadrics는 3D 모델 최적화, SLIM은 월드·배경 최적화로 분류합니다. KO는 이해를 돕는 번역 제목, EN은 원문 제목을 표시합니다. 하이퍼링크는 사용하지 않으며 원문 링크와 서지 정보는 연구 적용 문서에 보존합니다. SLIM은 기술 발표입니다.

팀의 적용 시도는 사용자 제공 문서에 근거합니다. 외부 출처는 연구 내용의 근거이며 팀의 구현 완료나 성능 개선을 증명하지 않습니다. CageNet은 향후 적용 검토, Cube는 탐색, 특징 보존 감소는 시험 단계로 표현합니다. SLIM은 연구 논문이 아닌 2025-12-05 공개 기술 발표로 구분합니다. Textured Mesh 논문은 arXiv 최초 공개 2024-09-23·개정/SIGGRAPH Asia 2025이며 원문의 단일 2025 표기를 보완합니다. 자동 아바타 셋업 연구를 R15 애니메이션 제작 완료로 확대 해석하지 않습니다.

- 17장 1단계 현황(2026.10.2): 01 AI 지형·02 R15 애니메이션·04 기본 전투 환경은 완료(녹색 텍스트), 03 아이템 및 UGC 제작 시스템은 진행 중. 사용자 제공 현황, KO/EN 표시.

- 18장 2단계 목표: 디아블로2 아이템 드랍 시스템(완료·녹색), RPG 스토리 콘텐츠(진행 중)를 01·02로 추가. 기존 6개 운영 목표를 03 데이터·지표·콘텐츠 소진 분석, 04 이벤트·커뮤니티 경험 및 노하우, 05 운영 주기·시스템의 3개로 통합. 기존 운영 목표의 완료 상태는 제공되지 않아 상태를 추가하지 않음.

- 16~20장 영문 교정: 운영 기반·운영 노하우·콘텐츠 소진 속도·이벤트/커뮤니티 운영을 자연스러운 표현으로 정리. 디아블로2 방식의 드랍 시스템은 Diablo II-style로 명확화. 20장은 현재 적용 실험과 향후 프로젝트별 검증을 완전한 문장으로 구분. 연구 서지·날짜·진척도·완료 상태는 유지.
