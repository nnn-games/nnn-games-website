### 16장 월간 타임라인

각 단계 카드에 프로젝트명을 추가합니다. 하단은 2026년 9월~2027년 2월의 월간 타임라인이며, Enchant a Weapon은 파랑·Hunt a Slime은 초록·Tomato Splatter는 빨강으로 구분합니다. 각 프로젝트의 출시 예정 월(10월·11월·2월)에 개발 진척도 60%·25%·5%를 표시합니다. 막대 길이는 해당 월 칸 안의 개발 진척도이며 개발 기간이나 시간 경과를 뜻하지 않습니다. 별도로 제공되지 않은 프로젝트 시작일이나 월별 예상 진척도는 추정하지 않습니다. 진척도 기준일은 2026-10-02입니다.

### 20장 연구의 실전 적용

사용자 제공 [연구 적용 문서](roblox_research_to_project.md)를 요약했습니다. 원문은 자료로만 다루고 공개 링크의 초록·공식 설명을 2026-10-02 확인했습니다. 3D 생성(Cube), 메시 최적화(Textured Mesh Simplification·Line Quadrics), 캐릭터 셋업(Automatic Avatar Setup·CageNet), 월드 최적화(SLIM)의 4영역과 제작 흐름을 KO/EN으로 표시합니다. 각 영역에 문서의 원문 링크를 연결했습니다.

팀의 적용 시도는 사용자 제공 문서에 근거합니다. 외부 출처는 연구 내용의 근거이며 팀의 구현 완료나 성능 개선을 증명하지 않습니다. CageNet은 향후 적용 검토, Cube는 탐색, 특징 보존 감소는 시험 단계로 표현합니다. SLIM은 연구 논문이 아닌 2025-12-05 공개 기술 발표로 구분합니다. Textured Mesh 논문은 arXiv 최초 공개 2024-09-23·개정/SIGGRAPH Asia 2025이며 원문의 단일 2025 표기를 보완합니다. 자동 아바타 셋업 연구를 R15 애니메이션 제작 완료로 확대 해석하지 않습니다.
