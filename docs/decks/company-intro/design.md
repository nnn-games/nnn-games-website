# 이미지에 맞춘 회사 소개 레이아웃

수정일: 2026-10-01  
대상: 본편 13장·부록 4장, KO/EN/JA, 데스크톱·모바일·인쇄

## 제목과 구두 설명

사용자 요청에 따라 전체 슬라이드의 서브타이틀을 제거한다. 표지의 회사 설명·소개 문구와 문의의 도입 문구도 같은 기준을 적용한다. 제목과 본문 사이에는 데스크톱 1.4rem·모바일 1.2rem 간격을 두고, 이미지·카드·표·연락처를 바로 이어 배치한다. 회사연혁 하단에 반복된 도입 문구도 제거한다. 발표자가 말로 설명할 문구는 [발표 메모](speaker-notes.md)에 보관한다.

## 이미지 사용 원칙

이미지는 설명을 담은 발표 자료다. 게임 화면의 HUD, 포스터 제목, 캠페인 참여 조건, 제작물과 포트폴리오를 포함한 원본 전체를 보존한다. 카드 크기를 맞추기 위해 이미지 일부를 잘라내지 않는다.

- 정적 이미지의 원본 `width`·`height`를 HTML에 기록하고 CSS `height: auto`로 종횡비를 보존한다. 팀 아바타는 공통 렌더러로 생성하고 원본 캔버스와 같은 720:687 프레임에서 `contain`으로 전체를 표시한다.
- `object-fit: cover`, 원본과 다른 강제 종횡비, 이미지를 가리는 카드의 `overflow: hidden`을 사용하지 않는다. 10 팀소개는 사용자가 지정한 nnn 원본 구성의 크기·위치·기울기·배경 강조를 재사용한다.
- 이미지 폭은 슬라이드의 정보량에 맞춰 배분하고 높이는 원본 비율에서 결정한다. 여러 이미지 비율이 다르면 높이·카드 끝선을 억지로 통일하지 않는다.
- 배너와 정사각형을 함께 놓을 때 각각의 비율에 맞춰 열 너비를 정한다. 모바일에서는 세로로 펼쳐 각 이미지를 충분한 폭으로 표시한다.
- 투명 아바타·UGC와 포트폴리오도 전체를 표시한다. 포트폴리오를 좁은 띠에 끼우지 않는다.
- 모바일은 이미지·설명을 함께 세로로 읽으며 필요한 슬라이드는 스크롤한다. 인쇄에는 17장 전체를 1280×720px로 배치한다.

원본 파일 46개를 53개 이미지 요소로 배치한다. 이미지가 있는 슬라이드는 14장이다. 10 팀소개의 내용·구성은 nnn 원본으로 복원했으며 다른 슬라이드의 내용과 지표는 유지한다.

## 검증 기준

전체 17장의 KO/EN/JA × 1280/390/320px 브라우저 검사와 변경 화면 PNG 직접 확인을 실행한다. 각 이미지의 자연 비율이 유지되는지, 이미지가 슬라이드나 부모 요소에 잘리는지 확인한다. 팀 슬라이드의 회전은 원본 합성 의도에 따라 허용하며, 회전된 경계 상자의 비율 대신 원본 이미지와 contain 프레임의 비율을 확인한다. 인쇄 모드도 같은 기준으로 확인한다. 모바일의 슬라이드 스크롤은 허용하며 이미지 자체를 크롭하지 않는다.

이미지 원본 경로와 내용 근거는 [제작 출처](sources.md), 목차·본문은 [슬라이드 구성안](slide-outline.md)을 따른다.
