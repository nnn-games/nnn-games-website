# 프로젝트별 기획·참고 자료

각 상세 페이지의 실제 노출 데이터(카피, 메타, 링크, 에셋)를 KO/EN/JA 3개 언어 기준으로 정리하기 위한 페이지별 계획서입니다.

- 표준 골격: [`_template.md`](_template.md)
- 데이터 반영 순서: 본 계획서 확정 → `shared/data/projects.json` 메타 갱신 → `site/js/project-details/<slug>.js` 콘텐츠 입력 → 로컬 빌드 검증
