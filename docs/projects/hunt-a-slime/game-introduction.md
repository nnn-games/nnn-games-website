## 메인 카피

쏟아지는 슬라임을 처치하고, 전리품으로 더 강해지세요.

Hunt a Slime은 몰려오는 슬라임을 사냥하고, 전리품을 모아 캐릭터를 성장시키는 Roblox Action RPG입니다. 더 좋은 장비와 자신만의 스킬 조합으로 더 강력한 슬라임과 보스에 도전하는 모험을 목표로 개발 중입니다.

## 핵심 피처

- 쏟아지는 슬라임 무리를 처치하며 시원한 액션을 즐기세요.
- 전리품을 모으고 장비와 스킬을 조합해 나만의 캐릭터를 키우세요.
- 분열·합체하는 슬라임과 거대한 보스에 도전하세요.

지역 탐험 → 슬라임 사냥 → 전리품 획득 → 장비 교체·스킬 성장 → 다음 지역과 보스에 도전

## 세계관

생명의 점액이 흐르는 세계 젤라리아(Gelaria). 온순했던 슬라임들이 오염된 원액의 영향으로 무엇이든 삼키며 세계를 뒤덮기 시작했습니다. 플레이어는 사냥꾼이 되어 숲과 폐허를 지나 슬라임 군주들을 추적합니다.

## 비주얼 방향

Roblox 베이컨 헤어 캐릭터의 자연스러운 자세와 블록형 비율, 매끈한 카툰 표현과 반투명 젤리 슬라임. 짙은 남색·보라색 숲과 폐허를 배경으로 라임색 슬라임, 빛나는 무기, 황금빛 전리품을 강조합니다. 어린 플레이어도 편하게 볼 수 있는 모험의 톤을 유지합니다.

## 제작 참고 · 홈페이지 비노출

전투·전리품·성장과 슬라임 고유 규칙은 앞으로 구현할 기획 내용입니다. 공개 Roblox 체험 주소와 출시 일정은 확정 후 추가하고, 플레이 버튼도 해당 주소가 준비되면 연결합니다.

사용자가 제시한 외부 프로젝트의 원본 참조: `assets/marketing/title/v1/title-screen-1920x1080.png`, `assets/marketing/v6/thumbnail-horde.png`, `thumbnail-loot.png`, `icon-slash.png`; 기획 정본 `design/concept.md`, `systems.md`, `story.md`, `roadmap.md`. 이 저장소에는 해당 경로가 없으며, 이번 홈페이지는 제공된 소개서와 이미 등록된 같은 용도의 홍보 비주얼을 사용합니다.

## 홈페이지 적용

- 다른 프로젝트와 동일한 표준 상세 레이아웃: 히어로 → main 대표 이미지 → 개요·핵심 포인트 / 우측 프로젝트 정보·특징.
- 개요에 게임 소개·세계관·개발 안내를 담고, 주요 특징에 플레이 흐름·대상 플레이어를 정리합니다. 별도 전용 섹션과 내부 개발 소식 버튼은 사용하지 않습니다.
- 상세·OG에는 main, 홈·목록 카드에는 preview만 사용합니다. 핵심 포인트는 텍스트로 표시하며 갤러리는 추후 개발 이미지가 준비되면 추가합니다.
- 개발 단계 및 계획된 기능임을 본문에 표시하고, 출시일은 추후 공개로 정리합니다.
- 카드·SEO·본문·이미지 대체 텍스트를 KO/EN/JA로 반영합니다.
