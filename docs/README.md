# 프로젝트 문서

코드는 `site/`, `decks/`, `shared/`에 있고 기획·원고·원본 자료는 이 폴더에서 관리합니다. 이 폴더는 배포되지 않습니다.

- [홈페이지](site/README.md): PRD, 화면 규칙, 지표 기준, 개발 계획
- [프로젝트](projects/README.md): 프로젝트별 기획서, 참고 이미지, 콘텐츠 템플릿
- [발표자료](decks/README.md): 회사 소개·제안 발표의 원고, 기획, 디자인 원본
- [개발 로드맵](development-roadmap.md): 프로젝트 전체 개발 기록
- [에이전트 개발환경](agent-development.md): OpenAI 공식 자료 조사, 공용 스킬·하네스·사용 예시
- [에이전트 실행 계획](agent-plans.md): 여러 단계 작업의 진행 상태와 검증 기록 형식

각 프로젝트는 `projects/<slug>/`, 각 발표는 `decks/<slug>/` 아래에 관련 자료를 모읍니다. 실제 화면에서 사용하는 이미지는 기존 `shared/assets/` 또는 `decks/<slug>/assets/`에 둡니다.
